# 正则化与稳健性结果

数据为11,809条大肠杆菌87 bp序列。对照使用相同特征、训练样本和CNN种子，扩展Ridge正则化范围；稳健性实验另含基因组区域分组、三种子归因与五次目标训练组抽样。

## 正则化对照

| 表征 | alpha不超过100时的R² | 扩展范围后的R² |
| --- | ---: | ---: |
| k-mer | 0.0727 | 0.0842 |
| 冻结DNA表征 | 0.0102 | 0.0659 |
| k-mer与CNN A1 | 0.0418 | 0.1174 |
| 继续加入DNA A2 | -0.0215 | 0.1100 |
| 继续加入归因区域 A3 | -0.0273 | 0.1144 |

A1至A3为三个匹配种子的指标均值。各源域头均选择alpha=10000，位于七档候选范围内部。结果表明回归头正则化会明显改变高维融合的表现；扩展后A2和A3仍未超过A1。该验证集参与选参，成绩按内部描述性比较解释。

## 区域分组验证

20 kb区域分组的train/dev/evaluation分别为5985/2003/1998条，跨集合窗口重叠为零。所有监督模型、归一化、热力学校准和归因选区按新train重新拟合，以dev选择参数。评价R²为k-mer Ridge 0.0868、纯CNN 0.0993、A1 0.1162、A2 0.1073、A3 0.1130。该结果来自一次内部空间划分。

## 解释与迁移

−10区域在IG与ISM、固定与PC推定窗口、Top-5与Top-10的组合中，三个CNN种子的平均富集均为正。跨种子的Top-5 Jaccard均值为IG 0.2024、ISM 0.2522，具体碱基位置的稳定性弱于区域层面。

100组few-shot冻结CNN的五次抽样Spearman为0.2075±0.0162，zero-shot CNN为0.2161。当前设置未呈现稳定的迁移增益。单次抽样的历史结果与当前结果还存在正则化范围差异。
