## 性能低包含参数问题，但仍不能保证高预测精度

| 同一原划分上的对照 | 原R² | 修订R² |
| --- | ---: | ---: |
| k-mer Ridge | 0.0727 | 0.0842 |
| 冻结DNABERT-2 + Ridge | 0.0102 | 0.0659 |
| A1：k-mer + CNN表征 | 0.0418 | 0.1174 |
| A2：继续添加DNA表征 | -0.0215 | 0.1100 |
| A3：继续添加归因区域特征 | -0.0273 | 0.1144 |

融合数值为三个匹配CNN种子的指标均值。原搜索在alpha=100处截断；扩展后各源域头均选择内部候选alpha=10000。
所以旧版“融合比常数预测还差”是旧参数范围下的结果，不能当作这类表征无用的证据。
但原验证集参与选参，上表也不能视为独立泛化提升。纯CNN原三种子均值R²为0.1160，A3修订后与其接近。

在两种划分的点估计中，A2都低于A1，A3有所回升但没有超过A1。因此，总体改善主要支持修正正则化；
没有证明添加DNA表征或归因特征能稳定优于k-mer+CNN表征。报告应保留这项负结果，不要求消融阶梯必须逐级上升。

修订后R²仍约0.1，解释度有限。当前实验没有分离标签噪声、天然表达与起始率差异、上下文长度和模型能力各自造成多少误差，不能选其中一个因素作为唯一原因。

## 更严格的分组对照支持什么

按20kb基因组区域分组，train/dev/evaluation为5985/2003/1998条；排除49条跨边界窗口，原历史test的1774条全部排除。
任意两集合之间，双链87bp窗口重叠均为0，相同序列及其反向互补副本也不跨集合。

| 分组评价 | R²均值 | Spearman均值 |
| --- | ---: | ---: |
| k-mer Ridge | 0.0868 | 0.2978 |
| 冻结DNA + Ridge | 0.0713 | 0.2673 |
| 纯CNN | 0.0993 | 0.2982 |
| A1 | 0.1162 | 0.3177 |
| A2 | 0.1073 | 0.3167 |
| A3 | 0.1130 | 0.3158 |

归一化、scaler、热力学校准和归因选区均只拟合新train；回归头alpha与CNN早停只看dev。
这些成绩没有出现整体崩落，不能把原来所有低分归咎于相邻窗口跨集合。
两种划分的样本组成不同，分数差也不能用来精确估计重叠带来的偏差。
本轮是一次内部空间分组对照，历史标签曾参与项目开发，未将其称为独立外部盲测。

区域bootstrap的配对差值见完整报告。它们是固定模型、固定分组下的描述性区间，多个对照未校正多重比较；不据其中一个较好的evaluation分数继续改模型再报同一集合。

## 位点结论更稳，具体位置仍有不确定性

−10区域在两个归因方法、固定/PC推定窗口、Top-5/10的所有组合中，三个CNN种子的区域平均富集均为正。
这使“−10区域受到模型关注”的描述比单种子时更有支持。

但跨种子的Top-5 Jaccard均值仅IG 0.2024、ISM 0.2522；精确到哪些碱基，稳定性明显弱于区域层面。
应报告区域富集和具体位点不确定性，避免把某一次Top-5清单当作确定的真实结合位点。
原来的计算突变结果仍解释原纯CNN，代表模型与变体设计没有被悄悄替换。

## 跨物种结论应收敛

100组few-shot冻结CNN在五次训练抽样中的Spearman为0.2075±0.0162，zero-shot CNN为0.2161。
旧版约0.263来自预定的一次抽样，没有据test挑选最佳种子。本轮同时扩大了alpha范围并改变抽样种子，不能把两轮分数差全部归因于抽样；
单次结果也不能代表稳定收益。本轮五次结果没有证明当前few-shot设置稳定优于zero-shot。
20组时不同抽样波动更大，所有预定抽样均保留。

目标域仍缺少测量单位、实验条件和TSS；这限制生物解释与绝对尺度比较，但不妨碍完成课程要求的跨物种排序对照。
没有为了填满实验而在未知TSS的61bp目标序列上使用固定TSS热力学模型。
