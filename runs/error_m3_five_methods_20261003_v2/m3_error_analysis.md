## 覆盖和解释

请求 val 样本数 1783；共同成功样本数 1782。各方法的请求、成功、失败数见 source_tables/coverage_summary.csv；精确评价 ID 见 common_eval_ids.tsv。指标均由逐样本预测重新计算，不使用队友汇总表中的全数据分母。

低/中/高边界来自 train log10 strength 的 1/3 和 2/3 分位数：1.940666、2.383259。每组 n、MAE 和偏差见 group_errors.csv。正偏差表示高估，负偏差表示低估；请结合散点与残差图解释均值收缩，不能把预测误差直接归因于某个生物学元件。

case_review.csv 包含每方法最大误差前5、方法分歧前5以及固定种子的5个随机共同样本；可能重叠，保留所有选择理由。所有案例先核对样本、划分、标签、序列，具体机制保持 unconfirmed。难例未删除。

## 当前完成边界

本轮已接入方法的验证集图表、分组误差、覆盖和案例可交接。教师 M3 要求简单 ML 与热力学，Ridge/SVR 是建议架构；组内另外承诺的 k-mer Ridge 交付状态见统一任务表。不能以图表生成完成代替所有中期任务验收。

校准输入既支持历史成功记录表，也支持保留失败请求的新表；失败不参与性能计算，但参与 coverage。模型 checkpoint 与 train-only 校准的独立复现见统一验收程序。热力学输入为补取的 150 bp 参考基因组上下文，CNN 为原始 50 bp；信息范围不同，测量上下文一致性、工具扫描位置和 assay 方向仍需核实。
